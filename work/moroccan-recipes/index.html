PROJECT

Moroccan Recipes

A Flutter and Firebase app for discovering, saving and cooking authentic Moroccan dishes, with a design inspired by Moroccan aesthetics.

  • Flutter
  • Firebase Auth
  • Cloud Firestore
  • Material Design
  • Email and password sign-in, anonymous browsing and password reset.
  • User profiles with saved recipes.
  • Role-based admin access for managing the recipe content.
  • Recipes and images served from Firestore with real-time updates.
  • A custom Material theme, responsive layouts and loading states.
