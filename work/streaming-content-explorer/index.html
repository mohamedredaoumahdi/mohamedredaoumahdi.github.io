PROJECT

Streaming Content Explorer

A native iOS app for discovering movies and TV shows: upcoming, trending and popular titles, with trailers, cast and crew details, and personal watchlists.

  • Swift
  • UIKit
  • Core Data
  • MVVM
  • TMDB API
  • SDWebImage
  • EventKit
  • Content from the TMDB API, with trailers from YouTube.
  • Watchlists saved on the device with Core Data.
  • A calendar of upcoming releases, with reminders added to the iOS calendar through EventKit.
  • Fast image loading and caching with SDWebImage.
  • UIKit with an MVVM architecture.
